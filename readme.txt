A modular, performance-first multipurpose WordPress theme built on a design-token system.

== Description ==

Evolyon is a multipurpose theme built around a single design-token system driving nine color palettes, independent light/dark modes, and full RTL support. See wp-content/docs/DOCUMENTATION.md for the complete guide and wp-content/docs/DEVELOPER.md for hooks, filters, and child-theme instructions.

Pair with the Evolyon Toolkit plugin (bundled separately, works standalone with any theme) for authentication, the frontend user dashboard, and the form builder.

== Installation ==

1. Upload and activate the theme.
2. Upload and activate the Evolyon Toolkit plugin.
3. (Optional) Import a starter demo from the "Evolyon Demos" admin menu.
